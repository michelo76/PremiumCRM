Now Playing Info

Control4 DriverWorks driver · version 1.0 · OS 3.1.3 or later

Now Playing Info figures out what is playing in a room and shows a rich “about what’s playing” page (poster, title, episode, synopsis, cast, ratings, progress) as a button in Navigator. It also exposes the information as variables and events for Composer programming (e.g. dim the lights when a movie starts). The driver is purely informational: it never controls playback.

Contents: Sources · Metadata API keys · Showing the button · Properties · Actions · Variables · Events · Programming examples · Limitations · Troubleshooting · Attribution

Quick start

  1. Add the driver to the room whose media you want to show (or set the Room property).
  2. Fill in at least one source below. With no other source, the driver uses the Control4 room’s own media information (on by default).
  3. Optional but recommended: enter a free TMDB API Key (posters, synopsis, cast) and an OMDb API Key (IMDb / Rotten Tomatoes / Metacritic ratings).
  4. Make the button visible in Navigator (see Showing the button) and refresh Navigators.
  5. Run the action Test Metadata Sources and check the Status property.

Sources (where “what is playing” comes from)

You can configure several sources at once; the driver shows the one that is playing (playing > buffering > paused > stopped/idle > off; ties go to Roku, then Apple TV, then Home Assistant, then Control4 room media).

Roku (Roku players and Roku TVs)

  • Set Roku Address to the Roku’s IP address (give it a DHCP reservation). Optional Roku Name is shown as the device name.
  • On the Roku: Settings › System › Advanced system settings › Control by mobile apps › Network access = Default (or Permissive). Otherwise the Roku answers “403” and the Status property says so.
  • Roku reports the app (Netflix, Hulu…) and play / pause / position, but not the title. For titles, also add the same Roku through Home Assistant and set Home Assistant Entity Is = Same Device As Roku. On a Roku TV’s antenna input the channel and, when guide data is present, the program are shown.

Apple TV (via the companion bridge)

  • Apple TV has no simple network API, so a small companion service, the Apple TV bridge, must run on an always-on computer on the same network (Raspberry Pi, NAS, Docker host). It ships with this driver’s source in the bridge/ folder; its README has the full steps:
    1. Install: pip install -r requirements.txt (or docker compose build).
    2. Find the device: python -m atv_bridge scan.
    3. Pair (enter the PIN shown on the TV): python -m atv_bridge pair "Living Room".
    4. Run it: python -m atv_bridge serve (port 8765), optionally with ATV_BRIDGE_TOKEN.
  • Driver properties: Apple TV Bridge URL = http://<bridge-ip>:8765, Apple TV Device = the device id, name or slug from scan, Apple TV Bridge Token = the token if you set one.
  • What you see depends on what the app publishes to the Apple TV’s now-playing center: the Apple TV app and Music are complete, many apps send only a title, some send nothing.

Home Assistant (anything HA can see: Apple TV, Sonos, Plex, Kodi, Chromecast, Android TV, Roku…)

  • Home Assistant URL = http://<ha-ip>:8123.
  • Home Assistant Token: in Home Assistant open your user profile › Security › Long-lived access tokens › Create token. Paste it here (it is stored as a password property).
  • Home Assistant Entity ID: the media_player.… entity (Developer tools › States).
  • Home Assistant Entity Is: Separate Device, or Same Device As Roku / Apple TV when the entity is the same physical box. The driver then merges HA’s titles into the Roku/Apple TV source instead of treating them as two players.

Control4 room media

  • Use Control4 Room Media = On (default) reads the room’s current media information that Control4 source drivers publish (title, artist, album, cover art), e.g. from Control4 music services or a media server.
  • Control4 does not publish play/pause for a room, so room media is shown as “playing” whenever the room is on and media information exists.
  • Show Only When Room Is On = On shows “off” whenever the room is off, regardless of the other sources (and stops polling them meanwhile).

Metadata API keys (optional)

ServiceWhat it addsHow to get a key
TMDB (The Movie Database)Posters, backdrops, logos, synopsis, tagline, cast & crew, genres, runtime, content rating, episode details, trailers. Free for non-commercial use: create an account at themoviedb.org › Settings › API. Paste either the API Key (v3) or the API Read Access Token (v4, starts with eyJ); the driver detects which.
OMDbIMDb rating and votes, Rotten Tomatoes and Metacritic scores, awards. (IMDb has no public API; OMDb is the practical way to get these ratings.) omdbapi.com › API Key (free tier: 1,000 requests/day; the driver caches results).
Gracenote (optional)Live-TV program guide data (what is on a channel now) and an alternative title search. Gracenote / TMS keys are licence-gated (commercial agreement). Leave empty if you do not have one. Gracenote Lineup ID (e.g. USA-OTA22201-DEFAULT) is needed for live TV.
Music LookupAlbum art, album year, genre, track list via Apple iTunes Search and MusicBrainz.No key needed. Turn off with Music Lookup = Off.

Metadata Language (default en-US) and Content Rating Country (default US) control TMDB’s language and which country’s rating (PG-13, TV-MA, FSK 12…) is shown.

Showing the button in Navigator

  1. In Composer Pro, select the room in the project tree › Navigators tab.
  2. Under Watch and/or Listen, find Now Playing (this driver’s button) and make it visible; move it to the position you like.
  3. Refresh Navigators (File › Refresh Navigators, or from the Navigators view).

Tapping the button opens the Now Playing page. The icon changes to a highlighted “playing” variant while something is playing. The page works on touch screens and in the Control4 app, including remotely: it receives its data through the Navigator, and artwork that lives on your LAN (Apple TV bridge, Home Assistant, NAS) is embedded by the controller (Embed LAN Artwork = On) so it also shows when the phone is away from home.

Events

EventFires when
Media ChangedA different title/track/channel is identified.
Playback StartedPlayback starts (from stopped/idle/off, or new media after a pause).
Playback PausedPlaying → paused.
Playback ResumedPaused → playing, same media.
Playback StoppedPlaying or paused → stopped, idle or off.
Details AvailableMetadata (poster, ratings, cast…) has been attached to the current media.
Source ChangedThe active source device changes.
App ChangedThe active app changes.
Movie Started / TV Episode Started / Music Track Started / Live TV StartedMedia of that kind starts playing (once per title).

Rebuffering does not fire stop/start events. After a driver restart the current state is reported once (e.g. Playback Started if something is already playing).

Programming examples

WHEN Now Playing Info  Movie Started
  Living Room Lights  Ramp to level 10 over 5 seconds

WHEN Now Playing Info  Playback Paused
  IF Now Playing Info  MEDIA_KIND  equals  movie
    Living Room Lights  Ramp to level 40 over 2 seconds

WHEN Now Playing Info  Playback Stopped
  Living Room Lights  Ramp to level 60 over 5 seconds

WHEN Now Playing Info  Details Available
  IF Now Playing Info  CONTENT_RATING  equals  R
    Kids Room Keypad  LED 3  Set color red

Variables can also be used in conditionals and in custom text (e.g. a keypad engraving or an announcement with DISPLAY_LINE_1).

Limitations (honest list)

  • Roku (ECP) reports the app and play/pause/position but no title. Combine it with Home Assistant for titles.
  • Apple TV: some apps publish no metadata at all (only playing/paused). Live TV apps rarely give a channel.
  • Control4 room media has no play/pause state; it is shown as playing while the room is on and media information exists. The exact format of the room’s “CURRENT MEDIA INFO” differs between source drivers; the parser is tolerant, but if titles are wrong use Print Room Media Info.
  • Metadata matching is by title (and year/season/episode when known); unusual titles, home videos and YouTube are deliberately not matched.
  • The web view on the on-screen (TV) Navigator is not supported by Control4 (undocumented); use touch screens and the Control4 app.
  • The Gracenote path is implemented to the published API but has not been tested against the live service.
  • Remote access: LAN artwork is embedded only up to 256 KB per image; larger images show on the LAN only.
  • The optional LAN web port has no authentication: only enable it on a trusted network.

Troubleshooting

SymptomCheck
Status: “Not configured”Enter a source, or set Use Control4 Room Media = On.
Status: “Roku ECP access denied (HTTP 403)”On the Roku set Control by mobile apps › Network access = Default/Permissive.
Status: “Roku unreachable” / “bridge: …”IP address changed? Use DHCP reservations. Is the bridge running (http://<bridge>:8765/v1/health)?
Home Assistant 401Create a new long-lived token; HA may temporarily ban an IP after failed logins.
No posters / synopsisRun Test Metadata Sources; check the TMDB key and that the controller can reach the internet.
Wrong movie matchedRun Clear Metadata Cache; very generic titles may match the wrong film. Send us Print State output.
Button missing in NavigatorMake it visible under the room’s Watch/Listen menus and refresh Navigators.
Page shows “reconnecting”The Navigator did not get data; check the driver is running (Status) and refresh Navigators.
Anything elseSet Debug Mode = Print, reproduce, and send the Lua output (keys are redacted).
